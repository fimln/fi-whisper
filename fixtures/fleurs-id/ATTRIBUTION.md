# Sampel ucapan Indonesia

Tiga WAV pertama dari split test Indonesia (`id_id`) FLEURS. File audio tidak diubah. Transkrip referensi diambil dari mirror, dengan pemilihan subset dan penambahan metadata/hash di manifest lokal.

- Pembuat dataset asli: Google/FLEURS, Conneau et al. (2022), dan kontributor FLEURS; distribusi WAV individual oleh FluidInference.
- Sumber asli: [Google FLEURS](https://huggingface.co/datasets/google/fleurs), [paper FLEURS](https://arxiv.org/abs/2205.12446).
- Distribusi file individual: [FluidInference/fleurs-full](https://huggingface.co/datasets/FluidInference/fleurs-full/tree/1cca811bb8ea4d370345f108f00518167040282c/id_id), revision `1cca811bb8ea4d370345f108f00518167040282c`.
- Transkrip: [id_id.trans.txt](https://huggingface.co/datasets/FluidInference/fleurs-full/blob/1cca811bb8ea4d370345f108f00518167040282c/id_id/id_id.trans.txt).
- Lisensi audio/transkrip: [Creative Commons Attribution 4.0 International](https://creativecommons.org/licenses/by/4.0/), sesuai metadata Google FLEURS dan kartu dataset mirror.
- Sampel: `id_id_0000.wav`, `id_id_0001.wav`, `id_id_0002.wav`. Manifest memuat SHA-256 dari metadata LFS mirror, bukan hash yang diasumsikan dari nama file.

Ini materi publik untuk smoke test, bukan rekaman pengguna dan bukan benchmark representatif seluruh bahasa Indonesia.
