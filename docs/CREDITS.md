- Token warna, gaya kartu, spacing, dan pengaturan font diadaptasi dari `fi-shortener/desktop/src/theme.rs`, dibaca sebagai referensi lokal. Logo fi-whisper mengikuti bentuk logo fi-shortener dengan palet amber, dibuat oleh `scripts/make-logo.py`.
- Ikon GitHub (`mark-github-24`), beranda (`home-fill-24`), serta `dash-24` dan `x-24`: [Primer Octicons](https://github.com/primer/octicons), GitHub Inc., MIT ([lisensi](../assets/icons/OCTICONS-LICENSE.txt)). Logo GitHub hanya dipakai sebagai tautan ke repo.
- Inter Regular, Medium, SemiBold: Rasmus Andersson / Inter contributors, SIL Open Font License 1.1. Lisensi lengkap: [Inter-LICENSE.txt](../fonts/Inter-LICENSE.txt).
- JetBrains Mono Regular: JetBrains, SIL Open Font License 1.1. Lisensi lengkap: [JetBrainsMono-OFL.txt](../fonts/JetBrainsMono-OFL.txt).
- Rune, rune-kit, rune-fx revision `a7f276c3630f85a06a0230295da4d2bd172d8d3b`: Anomaly, MIT, https://github.com/anomalyco/rune. Rendering GPU melalui wgpu 30 (MIT OR Apache-2.0).
- rfd 0.17.2: MIT, https://github.com/PolyMeilex/rfd.
- whisper-rs 0.16.0 / whisper-rs-sys 0.15.0 (Unlicense, https://codeberg.org/tazz4843/whisper-rs), membundel whisper.cpp 1.8.3 dan ggml (MIT) yang ditautkan statis ke exe.
- cpal 0.18.2 (Apache-2.0), rubato 5.0.1 (MIT OR Apache-2.0), rtrb 0.4.0 (MIT OR Apache-2.0), global-hotkey 0.9.0 dan tray-icon 0.26.1 (MIT OR Apache-2.0), windows-sys 0.61.2 (MIT OR Apache-2.0), serde/serde_json (MIT OR Apache-2.0).
- Worker Google Cloud: tokio 1.53.3, tokio-stream 0.1.17, dan tonic 0.14.6 (MIT); googleapis-tonic-google-cloud-speech-v2 0.37.0 (MIT OR Apache-2.0) beserta prost 0.14.4 (Apache-2.0); reqwest 0.12.24 (MIT OR Apache-2.0); TLS lewat rustls 0.23.46 (Apache-2.0 OR ISC OR MIT), rustls-webpki 0.103.16 (ISC), dan ring 0.17.14 (Apache-2.0 AND ISC). Layanan Chirp 3 sendiri tunduk pada ketentuan Google Cloud.
- Dependensi transitif lain berlisensi permisif (MIT, Apache-2.0, ISC, BSD-3-Clause, Zlib, BSL-1.0, Unicode-3.0, Unlicense, 0BSD, atau kombinasinya); daftar lengkap bisa dibuat dari `Cargo.lock` dengan `cargo metadata`.
- qwen3-asr 0.2.2 (MIT, https://github.com/alan890104/qwen3-asr-rs), disalin ke `vendor/qwen3-asr` dengan patch fi-whisper (layout checkpoint `*-hf`, pembatalan antar-operasi encoder dan antar-layer encoder/decoder (termasuk prefill), validasi `config.json`, loader mmap Windows dengan proteksi write/delete, pemuatan tokenizer paralel, dan pengurutan logit diagnostik yang menerima NaN); memakai candle-core/candle-nn 0.9.2 (MIT OR Apache-2.0), memmap2 0.9.11 (MIT OR Apache-2.0), tokenizers 0.22 (Apache-2.0) dengan onig (MIT), safetensors (Apache-2.0), hound 3 (Apache-2.0), rustfft 6 (MIT OR Apache-2.0), dan rubato 0.15 (MIT).
- Bobot [Qwen/Qwen3-ASR-0.6B-hf](https://huggingface.co/Qwen/Qwen3-ASR-0.6B-hf) dan [Qwen/Qwen3-ASR-1.7B-hf](https://huggingface.co/Qwen/Qwen3-ASR-1.7B-hf): Alibaba Qwen, Apache-2.0. Tidak dibundel.

Uji model terpisah memakai CLI resmi [whisper.cpp b5454](https://github.com/ggml-org/whisper.cpp/releases/tag/b5454) (MIT), bobot Whisper large-v3-turbo (MIT), serta model [Silero VAD](https://github.com/snakers4/silero-vad) v6.2.0 dalam format ggml (MIT). Runtime uji dan library CUDA distribusi upstream disimpan lokal di `.local/`, tidak dibundel ke aplikasi UI atau dipublikasikan ulang. Lisensi/distribusi library NVIDIA perlu ditinjau saat membuat paket produk. Sampel FLEURS berlisensi CC BY 4.0: lihat [atribusi fixture](../fixtures/fleurs-id/ATTRIBUTION.md).

Model tidak dibundel; pengguna memilih file Whisper/Silero dan folder Qwen3-ASR sendiri. Paket CUDA menyertakan `cublas64_13.dll`, `cublasLt64_13.dll`, `nvrtc64_130_0.dll`, `nvrtc-builtins64_132.dll`, dan `curand64_10.dll` dari CUDA 13.2.2 (redistributable di bawah NVIDIA CUDA EULA, disalin ke `licenses/NVIDIA-CUDA-EULA.txt`); cudart ditautkan statis. Source proyek memakai [lisensi MIT](../LICENSE), mengikuti lisensi yang sudah ditetapkan pada remote. Font dan dataset mengikuti lisensinya masing-masing.
